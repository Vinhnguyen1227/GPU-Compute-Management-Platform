# Tech Context

## Tech Stack
### Frontend
- **Framework**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Lucide Icons + Custom Glassmorphism
- **Data Viz & UI**: Recharts (Telemetry & Metrics), XTerm/Simulated Log Terminal

### Backend Microservices Specs
- **.NET 9**: API Gateway, Auth, User, Payment, Wallet, Billing, Worker
- **Java Spring Boot 3**: Job Scheduler, Resource Manager, Project Service
- **Infrastructure**: PostgreSQL, Redis, Kafka, Docker, Kubernetes, Prometheus, Grafana

## Development & Test Commands
- Frontend Dev Server: `cd frontend && npm run dev`
- Frontend Build: `cd frontend && npm run build`
- Typecheck: `npx tsc --noEmit`
