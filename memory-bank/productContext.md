# Product Context

## User Problems Solved
1. **AI Infrastructure Management**: Simplifies submitting AI model training workloads to remote GPU pools.
2. **Resource Visibility**: Provides real-time metrics on GPU node utilization, temperature, and queue lag.
3. **Transparent Billing**: Tracks pay-as-you-go GPU compute usage, instant QR wallet top-ups, and ledger auditability.

## User Persona & Roles
- **AI Engineer / User**: Submits training jobs, uploads datasets, monitors real-time training progress & logs.
- **Infrastructure Admin**: Manages GPU nodes, handles maintenance drains, views system queue pressure, manages user quotas.

## UX Guidelines & Design Philosophy
- **Aesthetic**: Futuristic dark mode with NVIDIA DGX electric green (`#76B900`), deep cyan highlights, glassmorphic cards, smooth micro-animations.
- **Responsiveness**: Fluid layout with responsive navigation, collapsible sidebar, live metrics counters, interactive graphs.
